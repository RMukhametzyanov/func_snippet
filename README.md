# Folder Scanner Plugin for PyCharm

Плагин для PyCharm, который сканирует указанную папку и отображает её содержимое в виде дерева файлов. При выборе Python-файла показывает его структуру (классы, функции, методы) с возможностью просмотра мета-информации через всплывающие подсказки.

## Описание проекта

Это IntelliJ Platform плагин, разработанный на Kotlin для PyCharm. Плагин предоставляет удобный способ навигации по файлам проекта и просмотра структуры Python-кода.

### Основные возможности

- **Сканирование папок**: Укажите путь к любой папке, и плагин отобразит её содержимое в виде дерева
- **Фильтрация**: Автоматически скрывает папки `__pycache__` из дерева
- **Разделенное окно**: 
  - Слева: дерево файлов и папок
  - Справа: структура выбранного Python-файла (классы, функции, методы)
- **Парсинг Python-файлов**: Автоматически извлекает:
  - Классы
  - Функции верхнего уровня
  - Методы классов
  - Сигнатуры функций с типами параметров
  - Docstrings
- **Всплывающие подсказки**: При наведении на функцию или метод показывается:
  - Полная сигнатура функции
  - Docstring с описанием
  - Список параметров с типами, значениями по умолчанию и описаниями
  - Информация о возвращаемом значении
- **Открытие файлов**: Двойной клик по файлу открывает его в редакторе

## Требования

- **PyCharm 2024.1** или новее
- **JDK 17** или выше (для сборки плагина)
- **Gradle 7.0+** (загружается автоматически через wrapper)

## Установка

### Из собранного архива

1. Соберите плагин (см. раздел "Сборка")
2. Откройте PyCharm
3. Перейдите в `File → Settings → Plugins` (или `Ctrl+Alt+S`)
4. Нажмите на шестеренку и выберите `Install Plugin from Disk...`
5. Выберите файл `build/distributions/json-test-viewer-2.0.0.zip`
6. Перезапустите PyCharm

### Для разработки

1. Клонируйте репозиторий или откройте проект в PyCharm
2. Запустите плагин в режиме отладки:
   ```bash
   ./gradlew runIde
   ```
   Или в Windows PowerShell:
   ```powershell
   .\gradlew.bat runIde
   ```

## Использование

### Настройка

1. Откройте `File → Settings → Tools → Folder Scanner`
2. Нажмите "Обзор..." и выберите папку для сканирования
3. Нажмите "OK" для сохранения настроек

### Работа с плагином

1. Откройте боковую панель "Folder Scanner" (View → Tool Windows → Folder Scanner)
2. Плагин автоматически отобразит дерево файлов выбранной папки
3. Выберите Python-файл в дереве слева
4. Справа отобразится структура файла (классы, функции, методы)
5. Наведите курсор на функцию или метод для просмотра мета-информации
6. Двойной клик по файлу открывает его в редакторе

### Всплывающие подсказки

При наведении на элемент в дереве структуры отображается всплывающая подсказка с:

- **Сигнатурой функции**: Полное определение с типами параметров и возвращаемым значением
- **Описанием**: Docstring функции
- **Параметрами**: Список всех параметров с:
  - Именем параметра
  - Типом (если указан)
  - Значением по умолчанию (если есть)
  - Описанием из docstring (если есть)
- **Возвращаемым значением**: Тип и описание возвращаемого значения

## Компоненты плагина

### FolderTreePanel

Основной компонент, отображающий дерево файлов. Реализует:
- Сканирование указанной папки
- Фильтрацию папок `__pycache__`
- Разделенное окно (split pane) с деревом слева и структурой справа
- Обработку выбора файлов для отображения структуры
- Открытие файлов по двойному клику

### FileStructurePanel

Компонент для отображения структуры Python-файлов. Реализует:
- Парсинг Python-файлов для извлечения классов, функций и методов
- Построение дерева структуры
- Всплывающие подсказки с мета-информацией
- Парсинг docstring для извлечения описаний параметров

### FolderScannerSettings

Сервис для хранения настроек плагина (путь к папке для сканирования).

### FolderScannerConfigurable

UI компонент для настроек плагина, позволяющий выбрать папку для сканирования.

## Технические детали

### Парсинг Python-файлов

Плагин использует простой парсинг на основе регулярных выражений для извлечения:
- Определений классов (`class`)
- Определений функций (`def`)
- Сигнатур функций с типами параметров
- Docstrings (многострочные и однострочные)
- Информации о параметрах из docstring (секция `Params:`)
- Информации о возвращаемом значении (секция `Returns:`)

### Поддерживаемые форматы docstring

Плагин поддерживает docstring в формате Google/NumPy style:
- Секция `Params:` или `Args:` для описания параметров
- Секция `Returns:` для описания возвращаемого значения

### Фильтрация файлов

- Автоматически скрываются папки `__pycache__`
- Отображаются все остальные файлы и папки
